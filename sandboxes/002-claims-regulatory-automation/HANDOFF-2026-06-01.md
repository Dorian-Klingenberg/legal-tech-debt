## Active Scope

Sandbox 002 is the active proof-of-concept lane.

Focus only on Kentucky homeowners insurance and the five policy-layer smells:

1. Overbroad / Non-deterministic Exclusions
2. Magic Number / Magic Valuation Terms
3. Coverage Inversion / Contradictory Conditions
4. Calculation Rule Drift / Unversioned Rate Reference
5. Regulatory Mapping Smells

Do not start auto, personal auto, motor vehicle, no-fault, or PIP work unless the user explicitly reopens that scope.

Do not add infrastructure. This is still sandbox proof-of-concept work. Prefer small plain files, plain Python, Markdown, CSV, JSON, and readable outputs.

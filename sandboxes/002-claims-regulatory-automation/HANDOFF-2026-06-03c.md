## Summary

Phase 4 (semantic retrieval experiment) is complete. The result is a deferral, not a failure.

BM25 retrieval is 100% on the current 21-item gold set. Semantic retrieval (OpenAI text-embedding-3-small, cosine@10) scored 76% — but adds nothing on top of BM25, because all semantic misses are BM25 hits and semantic rescues zero BM25 misses. A vector store is not justified yet.

## Why Semantic Underperforms Here

The gold set queries were written using document vocabulary — they are phrase-matchable by design (that's how we confirmed the gold set items were correct). A fair semantic evaluation requires:

1. A second carrier's homeowners policy in the corpus (same smells, different language)
2. Gold set items written as plain-English reviewer questions, not document phrases
3. At least one documented BM25 failure that a concept-level query would fix

None of those conditions exist yet. When they do, Phase 4 re-opens. Until then, file-backed BM25 + phrase search is the correct retrieval stack.

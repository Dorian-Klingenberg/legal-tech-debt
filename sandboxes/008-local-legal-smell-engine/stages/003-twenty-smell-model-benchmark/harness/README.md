# Stage 003 Harness

The harness is intentionally small and dependency-free. `validate_packets.py` checks the manifest, packet completeness, case labels, local provenance IDs, and the required 8/8/4 complexity split.

Run from the repository root:

```powershell
python -B sandboxes/008-local-legal-smell-engine/stages/003-twenty-smell-model-benchmark/harness/validate_packets.py
```

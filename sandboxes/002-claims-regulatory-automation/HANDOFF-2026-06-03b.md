## Output Directory Convention

Each pipeline run writes to a timestamped subdirectory:
```
stages/002-homeowners-discovery-instrumentation/output/YYYYMMDD_HHMMSS_<run_id[:8]>/
```
`output/` is gitignored at each stage level. Retrieval runner and evaluator write their outputs back into the Stage 002 run directory.
